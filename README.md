Dragon Warrior PopTracker
-------------
A PopTracker pack for [Dragon Warrior (NES)](https://github.com/Serpikmin/Archipelago-DragonWarrior/releases) integrated with Archipelago.

Usage
- Download the latest release `.zip` from this repo
- Put the downloaded `.zip` into your PopTracker's `packs` folder, or drag it onto an open PopTracker window
- Connect to an active multiworld using the 'AP' button in the top-left

Features
- Autotracking with Archipelago
- Every map with all checks and full logic
- Searchsanity, shopsanity, levelsanity, and monstersanity support
- Progressive equipment tracking
- Your choice of DQ9 or DQ1 HD-2D sprites
